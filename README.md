# 📊 Curso de Analista de Datos — Edición Moderna (2026)

> Curso de **actualización nivel intermedio**, **Python-first**, con foco en las tecnologías y fundamentos actuales del análisis de datos: pandas/Polars, SQL moderno, el *modern data stack* y la **IA generativa aplicada** al trabajo diario del analista.

---

## 🎯 ¿Para quién es este curso?

Para personas que **ya conocen lo básico** (Excel, algo de SQL o estadística) y quieren
**modernizar su perfil**: pasar de hojas de cálculo a un flujo profesional reproducible,
con Python, control de versiones, un almacén de datos en la nube y asistentes de IA como
copiloto.

Al terminar serás capaz de:

- Montar un entorno de análisis moderno y versionado con Git.
- Limpiar, transformar y analizar datos con **pandas** y **Polars**.
- Escribir **SQL** analítico avanzado (CTEs, window functions, modelado).
- Hacer análisis exploratorio (EDA) y comunicar hallazgos con **storytelling**.
- Entender y usar el **modern data stack** (ELT, dbt, data warehouses).
- Usar **LLMs / IA generativa** de forma responsable como acelerador.
- Construir un **proyecto de portafolio** de punta a punta.

## 🧰 Stack de herramientas del curso

- **Lenguajes:** Python 3.12+, SQL
- **Librerías core:** pandas, Polars, NumPy, matplotlib, seaborn, plotly, scikit-learn, statsmodels
- **Datos:** DuckDB (local), BigQuery/Snowflake (cloud, conceptual), dbt
- **BI:** Power BI y/o Tableau (conceptual + práctica)
- **Entorno:** uv, Jupyter/VS Code, Git + GitHub
- **IA:** Claude / ChatGPT / Copilot como asistentes de análisis
- **Apps:** Streamlit para prototipos y dashboards

> No necesitas licencias de pago. Todo se puede seguir con herramientas gratuitas o
> capas gratuitas (free tier).

## ✅ Cómo aprovechar el curso

1. Sigue los módulos **en orden** (cada uno asume el anterior).
2. **Escribe el código tú**, no solo lo copies.
3. Haz cada bloque **▶️ Practica ahora** en el momento, antes de seguir leyendo. No los dejes para el final.
4. Usa la IA como **tutor**, no como muleta: pídele que te explique, no solo que resuelva.
5. Guarda todo en un **repositorio de GitHub** desde el módulo 02.

> 📌 **Dos carpetas distintas:** *"Curso Analista de datos"* es el **material** que lees (no es
> un repo tuyo). Tu **trabajo** vivirá en un proyecto aparte llamado `curso-datos`, que sí será
> tu repositorio de GitHub. El Módulo 02 lo explica en detalle — no los anides.
