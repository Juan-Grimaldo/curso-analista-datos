# Módulo 00 — Introducción

## Bienvenida

Este curso está pensado como una **actualización**: no partimos de "¿qué es una tabla?",
sino de "¿cómo trabaja hoy un analista de datos profesional y qué ha cambiado?".

En los últimos años el rol se ha transformado por tres fuerzas:

1. **Python se volvió el estándar** para análisis serio (por encima de Excel para tareas repetibles).
2. **El modern data stack** movió los datos a la nube (ELT, warehouses, dbt).
3. **La IA generativa** cambió *cómo* escribimos código y analizamos (copilotos, LLMs).

Vas a salir de aquí trabajando como se trabaja de verdad en 2026.

---

## Requisitos previos

Deberías estar cómodo/a con:

- Conceptos básicos de datos: filas, columnas, tipos de datos, tablas.
- Algo de Excel o Google Sheets (fórmulas, tablas dinámicas).
- Nociones básicas de SQL (`SELECT`, `WHERE`, `JOIN`) — aunque las repasaremos.
- Lógica básica de programación (variables, condicionales, bucles) es una ventaja.

Si algo de esto te falta, no pasa nada: los módulos 02–04 lo refuerzan.

---

## Qué necesitas instalar

Lo haremos con detalle en el **Módulo 02**, pero prepara:

- Una computadora con Windows, macOS o Linux.
- Conexión a internet.
- Una cuenta de **GitHub** (gratis).
- Una cuenta en un asistente de IA (Claude, ChatGPT o similar).

No instales nada todavía; el módulo 02 te guía paso a paso.

## Cómo está diseñado cada módulo

- **Teoría concisa** → lo justo para entender el *por qué*.
- **Código real** → ejemplos que puedes ejecutar.
- **Ejercicios** → para practicar.
- **Reto** → un mini-proyecto que integra lo aprendido.

> 💡 Regla de oro: si no lo escribiste con tus manos, no lo aprendiste.

## El mapa mental del analista de datos

```
    PREGUNTA DE NEGOCIO
            │
            ▼
    OBTENER DATOS ──────────► (SQL, APIs, archivos, warehouses)
            │
            ▼
    LIMPIAR / TRANSFORMAR ──► (pandas, Polars, dbt)
            │
            ▼
    EXPLORAR / ANALIZAR ────► (EDA, estadística)
            │
            ▼
    VISUALIZAR / COMUNICAR ─► (gráficos, dashboards, storytelling)
            │
            ▼
    DECISIÓN / ACCIÓN
```

Todo el curso gira alrededor de este ciclo. Cada módulo profundiza en una etapa.
